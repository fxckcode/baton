# Code of Conduct

Baton is a small open-source project. People contributing issues, reviews, and pull requests are expected to keep the discussion technical and respectful.

- Critique the change, not the person.
- Assume good faith, including when a parser is wrong.
- Do not post credentials, session files, or private account data in issues or pull requests. Redact them first.
- Harassment, slurs, and personal attacks are not welcome. Maintainers may hide or lock threads that go there.

Questions about a moderation decision can be raised with the repository maintainers.
